```bash
git clone <url-do-repositorio> GestaoNew
cd GestaoNew
```

---

## Configuração do Ambiente

### 1. Configurar Connection String do Oracle

Edite o arquivo `Empresa.Api/appsettings.Development.json`:

```json
{
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft.AspNetCore": "Warning"
    }
  },
  "ConnectionStrings": {
    "Oracle": "User Id=seu_usuario;Password=sua_senha;Data Source=(DESCRIPTION=(ADDRESS=(PROTOCOL=TCP)(HOST=localhost)(PORT=1521))(CONNECT_DATA=(SERVICE_NAME=XE)));"
  }
}
```

### 2. Configurar Serviço de E-mail (opcional)

Adicione no `appsettings.Development.json`:

```json
{
  "Email": {
    "smtpServidor": "smtp.seudominio.com",
    "smtpPort": 587,
    "smtpEmail": "naoresponda@seudominio.com",
    "smtpNome": "GestãoNew",
    "smtpSenha": "sua-senha"
  }
}
```

### 3. Pooling de Conexão (Recomendado)

A connection string deve incluir parâmetros de pooling:

```
User Id=...;Password=...;Data Source=...;Min Pool Size=2;Max Pool Size=20;Connection Lifetime=300;
```

## Compilando o Projeto

### Restaurar pacotes NuGet

```bash
dotnet restore
```

### Compilar toda a solution

```bash
dotnet build
```

O build deve ser bem-sucedido sem warnings para considerar o ambiente configurado.

---

## Executando a Aplicação

### API

```bash
# Perfil HTTP
dotnet run --project Empresa.Api --launch-profile http

# Perfil HTTPS
dotnet run --project Empresa.Api --launch-profile https
```

A API estará disponível em:
- HTTP: `http://localhost:5139`
- HTTPS: `https://localhost:7061`
- OpenAPI/Swagger: `http://localhost:5139/openapi/v1.json`

### Worker

```bash
dotnet run --project Empresa.Worker
```

```json
    }

    "smtpPort": 587,
    "smtpEmail": "...",
    "smtpNome": "GestãoNew",
    "smtpSenha": "..."
  }

```

### appsettings.Development.json (desenvolvimento)
```json
{
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft.AspNetCore": "Warning"
    }
  }
}
```

**Importante:** `appsettings.Development.json` faz merge (sobrescreve) sobre `appsettings.json`. Coloque apenas o que for diferente.

## Troubleshooting Comum

### Erro: Oracle connection não encontrada
**Solução:** Verifique se a connection string está correta em `appsettings.Development.json` e se o Oracle está acessível.

### Erro: PackageNotFound Oracle.ManagedDataAccess
**Solução:** Execute `dotnet restore` para baixar os pacotes NuGet.

### Erro: Build falha com CS0246 (namespace não encontrado)
**Solução:** Execute `dotnet build` pela raiz da solution (não por projeto individual) para garantir a ordem correta de compilação.
