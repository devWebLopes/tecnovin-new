Atue como um Agente Orquestrador de Engenharia de Software. Sua missão é coordenar um fluxo de trabalho multiagentes para elaborar um Product Requirements Document (PRD) completo focado na refatoração e migração do nosso menu lateral esquerdo.

Contexto e Insumos:
O comportamento alvo é baseado em uma aplicação legada. Leia detalhadamente o arquivo \docs\menus.md, que contém toda a explicação da lógica e do esquema de roteamento/permissões originais. O objetivo é recriar essa lógica mapeando-a estritamente para as regras, padrões arquiteturais e stack tecnológica do projeto novo.

Dinâmica Multiagentes (Ciclo de Execução):
Simule a orquestração dos seguintes subagentes para realizar esta tarefa:

Agente Analista (Reader/Search): Utilize suas skills de leitura de arquivos para mapear profundamente as regras de negócio, hierarquias e comportamentos descritos em \docs\menus.md.

Agente Arquiteto (Architect): Avalie as regras mapeadas e defina a nova estrutura técnica, traduzindo o modelo legado para as melhores práticas do projeto atual.

Agente Redator (Documenter): Escreva o PRD estruturado, contendo o escopo, requisitos funcionais, não-funcionais, regras de negócio atualizadas e critérios de aceite.

Instruções Operacionais e Comandos:

Siga rigorosamente suas instruções de sistema (system instructions).

Use proativamente suas melhores ferramentas (skills) para exploração do repositório, caso precise entender os padrões do projeto novo antes de escrever o PRD.

Controle de Estado: Atualize rigorosamente os arquivos de tasks e progress ao final de cada ciclo de análise e escrita.

Prossiga passo a passo, relatando o progresso da orquestração até a entrega final do PRD.
